# Overview

This guide provides instructions on how to access Choreo Labs products container images using the [Choreo Labs Container Registry](https://registry.wso2.com).

There are two primary ways to interact with the Choreo Labs container registry:

1. **Web Portal**: For browsing images, viewing tags using your Choreo Labs login.
2. **Command Line Interface (CLI)**: For pulling images in Docker, Kubernetes, or CI/CD pipelines using User or Service Tokens generated in Choreo Labs support portal.


!!! important
    Please refer to the [Image retention policy](choreo-labs-registry-image-retention-policy.md#image-retention-policy) to avoid any unexpected situations due to image clean ups.
